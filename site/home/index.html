ModsmithMC/modsmith

Modpacks, ready in the official launcher

Modsmith installs modpacks, mods, resource packs and shaders from Modrinth and CurseForge, and adds them to the official Minecraft launcher. You choose the installation there, and play.

Install Modsmith See how it works

Install

Two commands, and you are set

Modsmith runs in a terminal today, on Windows, macOS and Linux. A desktop app is on its way.

  1. Install uv, which brings the Python that Modsmith needs. In PowerShell:

    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

  2. Install Modsmith, in a new PowerShell window:

    uv tool install modsmith-cli

  1. Install uv, which brings the Python that Modsmith needs. In Terminal:

    curl -LsSf https://astral.sh/uv/install.sh | sh

  2. Install Modsmith, in a new Terminal window:

    uv tool install modsmith-cli

  1. Install uv, which brings the Python that Modsmith needs:

    curl -LsSf https://astral.sh/uv/install.sh | sh

  2. Install Modsmith, in a new terminal:

    uv tool install modsmith-cli

Then install your first modpack with modsmith install fabulously-optimized. Already have uv or pipx, or want to upgrade? See every way to install.

How it works

From a name to a game

  1. Install a pack Name a modpack from Modrinth or CurseForge, or give a file. Modsmith shows what it will add, and asks.
  2. Open the launcher The pack has its own installation, with its icon, Minecraft version and mod loader ready.
  3. Play Choose it and press Play. Your other installations stay as they were.

What it does

Everything a modded game needs

Modpacks

From Modrinth, CurseForge or a file, with the right Minecraft and mod loader.

Mods, resource packs and shaders

Add them to any pack, with the mods they need. Remove them as cleanly.

Updates that keep your changes

Update the pack and what you added. Your settings and edits stay.

Bring your own

Take over an installation you set up in the launcher, mods and all.

Every major loader

Forge, NeoForge, Fabric and Quilt, installed for you.

Blocked downloads

CurseForge files you must fetch by hand are found and checked.

Safe to try

It stays out of your way

No account

Modsmith never signs in, and never starts the game. The official launcher does both, as it always has.

You see it first

Every change is listed before it happens, and waits for your yes.

Nothing half done

A failed install or update leaves everything as it was.

For developers

Build your own tools

Everything Modsmith does comes from its Python library. Use it to write your own installer, updater or launcher helper.

Read the library's guide →

import modsmith as ms

with ms.platforms.Modrinth("my-tool/1.0") as modrinth:
    project = modrinth.get_project("fabulously-optimized")
    release = next(modrinth.iter_releases(project))
    print(release.name)
